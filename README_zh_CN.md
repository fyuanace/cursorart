# 入门主题模板

叠在官方 **daylight** 之上的布局主题：配色与组件变量复用 daylight，本主题只改四分区布局。

## 开始

1. 编辑 `theme.css`（只加布局覆盖；改颜色请优先改/依赖 daylight 变量）
2. 思源：**设置 → 外观 → 主题** → 选择 **入门主题模板**
3. `Ctrl+Shift+I` → Network 勾选 Disable cache → 控制台 `location.reload()`

## 文件

| 文件 | 作用 |
|------|------|
| `theme.json` | 元数据 |
| `theme.css` | 布局覆盖（叠在 daylight 上） |
| `icon.png` | 图标 |
| `preview.png` | 预览图 |

官方样板：https://github.com/siyuan-note/theme-sample
