## 背景信息

官方书签写在文档 IAL 里，和「我常打开的几篇」不是一回事。用户希望在面包屑上快速收藏当前文档，并在左侧文档树顶部单独看到这份名单。

## 当前方案

- 配置 `showFavoriteDocs`（缺省 `true`）、`favoriteDocs: { id, title, icon }[]`（最多 100 条，新收藏在前）与 `favoriteDocsMax`（缺省 `8`，范围 1–32）
- 保存其它设置时与现有配置合并，不会冲掉收藏
- 收藏按钮为五角星，插在面包屑右侧工具栏最左（定位到文档树按钮左侧）；已收藏实心 `#f6c050`，未收藏空心；按钮沿用官方 `block__icon` 尺寸，不另缩内边距
- 文件树「收藏」与「最近打开」、官方树包在同一滚动容器里，不再自带滚动条；关闭「显示收藏」只去掉该区块，五角星与名单仍在；分组之间不加分割线，用底边距分开
- 默认只列出 `favoriteDocsMax` 条；超出后出现「更多」，点开显示全部，再点「折叠」收回
- 无收藏、关闭显示或条数无效时不插入区块
- 点击条目打开文档；高亮钉在刚点的收藏项上，同时去掉官方 `ul[data-url]` 里的 `b3-list-item--focus`，并保持 `.starter-file-scroll` 滚动位置，避免共用滚动区被官方 `scrollIntoView` 拉到树里。点文档树或顶栏 Tab 时清掉收藏与最近打开的选中，整列只留当前点中的那一条。最近打开同一套逻辑
- 行内关闭按钮取消收藏；标题栏可折叠整块；条目带官方折叠占位（箭头隐藏），图标与文档树对齐
- 标题/图标在收藏当下从标题栏与文件树快照，不写文档属性
- 文档被删除（含删父文档带走的子文档）后，从 `favoriteDocs` 去掉对应 id 并写回配置。删除事件来自内核主 WebSocket 的 `removeDoc`（`ids` 含自身与子文档）；启动与树节点消失时再用 `getPathByID` 扫已不存在的条目

## 其他模块引用约束

- 不要把收藏写进文档 IAL / 官方书签
- 条目不要标 `data-type="navigation-file"` / `navigation-root`
- 不要改面包屑官方 `data-type="doc|more|readonly"` 按钮本身
- 不要给收藏/最近打开单独设 overflow，滚动只放在 `.starter-file-scroll`

## 工程师测试验收方法

1. 开启「加载主题 JS」，reload 后面包屑右侧工具栏最左（定位图标左侧）应有空心五角星，外框与旁边工具按钮一样大
2. 点击收藏：星星实心 `#f6c050`，文件树顶部出现「收藏」并含当前文档
3. 再点星星或列表里的关闭：该文档从收藏消失；全部取消后区块移除
4. 收藏超过设置条数时出现「更多」；点开看到全部，再点「折叠」只留设置条数
5. 样式页签关闭「显示收藏」：区块消失，五角星仍可收藏；再打开应看到名单；拖动条数只改默认列出数量；取消后回到保存值
6. 收藏与最近打开、文档树应共用一条滚动条
7. 保存其它主题设置后，收藏名单应仍在；重启后星星状态仍在
8. 切换离开本主题：按钮、区块与滚动包裹被清掉
9. 点击收藏条目：该项保持选中底色，官方文件树与最近打开都不应再高亮；再点文件树或顶栏 Tab：收藏与最近打开取消选中，只留文档树当前项
10. 删除一篇已收藏文档（或删除其父文档）：该项从收藏消失；名单空了则区块移除
