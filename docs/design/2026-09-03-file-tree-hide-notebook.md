# 文件树隐藏笔记本

## 变更记录

| 时间 | 说明 |
|------|------|
| 2026-09-03 | 侧栏开关：隐藏 `navigation-root`，自动展开笔记本并把文档缩进减一层 |
| 2026-09-03 | 缩进改为 CSS 按嵌套层覆盖，展开子文档时不再先多一层再收回 |
| 2026-09-03 | 开关改到设置「样式」页签 |

## 背景信息

官方文件树第一级是笔记本。用户希望不显示笔记本名称，直接把各笔记本里的文档当作第一级列出。

## 当前方案

- 配置 `hideNotebooks`（缺省 `false`）；开启时 `html` 带 `starter-hide-notebook`
- CSS 隐藏 `li[data-type="navigation-root"]` 与已关闭笔记本区块
- 开启后自动点开未展开的笔记本，以便子文档加载进 DOM
- 文档缩进用 CSS 按 `ul[data-url]` 下的嵌套层覆盖官方行内 `padding-left` / `--file-toggle-width`（少一层），插入时即正确位置
- 不改文件树数据，不删 DOM；关掉开关后官方行内缩进自行生效
- 设置里拨开关即时预览；取消 / Esc / 点遮罩还原

## 其他模块引用约束

- 只动 `#layouts .sy__file`，不要扩到大纲或反向链接树
- 不要在隐藏模式下拦截文档项的展开/折叠
- 不要在插入后再用 JS 改 `padding-left`（会先按官方多一层再收回）

## 工程师测试验收方法

1. 设置「样式」打开「隐藏笔记本」并保存：文件树不见笔记本名，其下文档顶到第一级
2. 展开带子文档的项：子项一出现就在正确缩进，不应先多缩一层再跳回
3. 关闭开关：笔记本行与缩进恢复
4. 多个已打开笔记本时，各笔记本文档依次列出，中间无笔记本标题
5. 切换离开本主题：类名与观察者被清掉

## 其他说明

未打开的笔记本不会出现文档（官方未加载子树）。需要先在官方界面打开该笔记本，或本开关会尝试展开已列出的笔记本。
